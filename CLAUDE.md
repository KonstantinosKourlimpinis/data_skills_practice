# data-skills-practice

## What this is
A personal learning project for practicing data science fundamentals: data cleaning, data preparation, EDA, time series forecasting, and ML. Not a production codebase.

## Dataset
**UCI Bike Sharing Dataset** — hourly bike rental counts in Washington D.C., 2011–2012.

**Download steps:**
1. Go to: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset
2. Download the zip
3. Extract `hour.csv` into `data/raw/hour.csv`
4. You can ignore `day.csv` — notebook 04 aggregates hourly data to daily itself

**Key columns:** `dteday` (date), `hr` (hour), `season`, `weathersit`, `temp`, `hum`, `windspeed`, `cnt` (target: total rentals)

## Environment setup
```bash
cd data-skills-practice
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
Then in VS Code: `Cmd+Shift+P` → "Python: Select Interpreter" → choose `.venv`.

## Notebook order
Run them in sequence — each notebook saves outputs that the next one reads:
1. `01` → saves `data/processed/hour_clean.csv`
2. `02` → saves `X_train/X_test/y_train/y_test` CSVs + `scaler.pkl`
3. `03` → reads `hour_clean.csv` (EDA, no output saved)
4. `04` → reads `hour_clean.csv` and aggregates to daily itself
5. `05` → reads train/test CSVs from `02`

## Current status
All notebooks are **skeletons** — cells are scaffolded with structure and starter code, but marked `# TODO` sections need to be filled in. This is intentional: the learning value is in completing them.

## Working conventions
- Notebooks use relative paths (`../data/...`) from the `notebooks/` directory
- `src/utils.py` has three helpers; add more shared functions there as needed
- No logging, no config files — this is a learning project, keep it simple
- Prefer explicit over abstract — don't refactor into classes unless it genuinely helps understanding

## If you ask Claude for help

- Share the error message or the cell output if something fails
